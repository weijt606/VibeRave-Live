# Reference: genre DNA — hard / club rows (pro mode)

Read with `reference/genre-dna.md` (same columns, same groove and finish
vocabulary). `mode:'pro'` defaults to this pool (`rules/pro-brief.md`). Same contract —
tempo, groove, one signature element inside two bars — but written for a
PA: the kick is at 0.95–1.0, the sub is mono, and every row has a drop.
`hard techno`, `hardstyle`, `psytrance` above apply here unchanged.
