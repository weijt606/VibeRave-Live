# Reference: genre DNA (v2)

The hard / club rows live in `reference/genre-dna-pro.md` (pro mode) and
the kids styles in `reference/genre-dna-kids.md` (family mode).

A named genre is a contract. Within two bars the crowd must hear the
tempo, the **groove**, the **low end** and the **signature**; within eight
bars they must hear the **finish** (what the mix is made of: dry or deep,
clean or saturated, wide or mono). Everything else is yours. Each row
gives three different ways to sound like the genre — pick the one that
fits the `<seed>` palette, never the same one twice in a row.

## How to read a row

| Column | What it fixes |
| --- | --- |
| Genre (BPM) | midpoint; the seed's tempo offset is added to it |
| Groove | the drum feel: kick placement, hat subdivision, swing amount, accents, ghosts, who carries the pulse |
| Low end | sub type + mid-bass design (`reference/palette.md` controls), and how they are separated |
| Harmony · hook | mode colour, chord types, the hook instrument, phrase length |
| Signature · finish | the one move that names the genre, and the mix finish — dry/wet, saturation, width, what gets space |
| Three ways | kit + sounds, A / B / C |
| Never | the cliché that turns this genre into another one |

Groove vocabulary (write it, do not just name it):
`straight` plain 16ths · `swing16 x` = `.swingBy(x, 8)` (0.06 subtle, 0.12
heavy) · `swing8 x` = `.swingBy(x, 4)` · `shuffle` = triplet hats
`"[hh hh hh]*4"` or `hh*12` · `laid-back` = `.late("[0 .012]*4")` on hats /
snare · `pushed` = `.early(0.01)` on the snare · `half-time` = kick 1, snare
3 · `2-step` = kicks `bd ~ ~ bd ~ ~ bd ~`-like with skipped beats · `dembow`
`bd ~ ~ bd ~ ~ bd ~, ~ ~ ~ sd ~ ~ sd ~` · `tamborzão` `bd ~ lt bd ~ cp ~ lt`
· `amen` = `s("brk").fit().slice(8, …)` · `triplet toms` = `"[lt mt lt]*4"`
· `polymeter` = `{…}%5` or `.slow(3)` against 4/4. Accents: hats
`.gain("[.9 .5 .7 .5]*4")`, ghosts `hh?` / `.degradeBy(0.12)`, round-robin
`.n(irand(4))` on sampled percussion, drift `.speed(perlin.range(0.96, 1.03))`.

Finish vocabulary: `tape` `.vib(0.4).vibmod(0.12).crush(10).lpf(5000)` ·
`vinyl` `s("pink*16").hpf(6000).gain(0.12).degradeBy(0.6)` · `analog drift`
`.detune(perlin.range(0.05, 0.25))` / `.speed(perlin.range(…))` · `glue`
`.shape(0.2–0.35)` on bass or drum bus · `grit` `.coarse(3–8)`, `.distort(0.3–0.7)`
· `air` `.hpf(8000)` on hats + a `white` layer `.decay(0.03)` · `depth` ONE
element `.room(0.5).roomsize(4).roomlp(5000)` · `tempo delay` ONE element
`.delay(0.3).delaytime(0.375).delayfeedback(0.5)` · `width` `.off(1/8, x => x.pan(0.2))`,
`.jux(rev)`, `.pan(sine.range(0.3, 0.7).slow(7))` · `motion` `.phaser(0.3).phaserdepth(0.6)`,
`.tremolo(6).tremolodepth(0.4)`, `.pw(sine.range(0.2, 0.6).slow(8))` ·
`transient` `.penv(-12).patt(0.06)` on kicks / 808s, `.lpenv(4).lpa(0.005).lpd(0.1)`
plucks · `sidechain` kick `.duckorbit(1).duckdepth(0.6).duckattack(0.08)`, ducked
layers `.orbit(1)`.

in all six; the rhythm comes from the second word.
